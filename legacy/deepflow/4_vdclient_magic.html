🧙‍♂️ vdclient Magic 使用教學¶

這份 Notebook 是為了協助 第一次使用 vdclient magic 的使用者 能夠快速上手。 vdclient magic 是一套支援多種 RDB 資料來源的查詢工具，特別設計給在 Jupyter Notebook 環境中進行互動式開發的資料科學家與分析師使用。

%vdclient -h：說明vdclient使用方式¶

In [1]:
%vdclient -h

📖 %vdclient / %%vdclient Magic 指令說明

🧩 Cell Magic（%%vdclient）

  • %%vdclient -d mydb -v df_result：查詢 SQL 並將結果存入變數 df_result
  • %%vdclient -d mydb -e result.parquet：查詢 SQL 並將結果匯出為 Parquet 檔案
  • %%vdclient：若未指定 -d，則使用 %vdclient --connect 所設定的預設連線

🧩 Line Magic（%vdclient）

  • %vdclient --connect -d mydb：設定預設連線為 mydb
  • %vdclient -t -d mydb：顯示 mydb 的資料表清單
  • %vdclient -h：顯示這份說明
